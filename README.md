# 복지용구 상담사 온라인 교육원

저장소 연동 전 전체 수강 흐름을 확인할 수 있는 1차 웹앱입니다.

## 실행

가장 간단한 방법은 `테스트페이지 실행.cmd` 파일을 더블클릭하는 것입니다.

이 폴더에서 아래 명령을 실행한 뒤 브라우저에서 `http://localhost:8080`을 엽니다.

```powershell
node server.js
```

인터넷 설치 없이 실행하려면 Python이 설치된 환경에서 다음 명령도 사용할 수 있습니다.

```powershell
python -m http.server 8080
```

## 데모 정보

- 학번: `2026001`
- 이름: `홍길동`
- 생년월일: `900101`

관리자 로그인:

- 아이디: `admin`
- 비밀번호: `admin`

현재는 공개 샘플 영상 하나가 8개 강의에 공통으로 연결되어 있습니다. `app.js`의 `CONFIG.lessons`에서 제목, 설명, 영상 주소를 실제 데이터로 교체할 수 있습니다.

## 현재 구현 범위

- 학번·이름·생년월일 일치 로그인
- 8개 강의 탭 및 이어보기
- 일시정지·배속·앞으로 건너뛰기를 제외한 연속 재생 진도 기록
- 8개 강의 완료 전 시험 응시 차단
- 시험 답안 제출 및 완료 안내
- 새로고침 후 로그인·진도·제출 상태 유지

## 다음 연동 단계

현재 데모는 브라우저의 로컬 저장소를 사용합니다. 운영 배포 전에는 로그인 검증, 진도 검증, 시험 접근 권한, 답안 저장을 서버에서 처리해야 합니다. Google Sheets는 관리자 결과 조회·내보내기 용도로 연결하며 인증정보를 브라우저 코드에 넣으면 안 됩니다.

## Google 결과표 연결

Google Drive에 `복지용구 상담사 교육 결과 관리대장`이 생성되어 있습니다. `google-apps-script.gs` 내용을 Google Apps Script에 붙여 넣고 웹 앱으로 배포한 뒤, 발급된 `/exec` 주소를 `app.js`의 `resultsEndpoint`에 입력하면 진도와 시험 결과가 자동 저장됩니다.
